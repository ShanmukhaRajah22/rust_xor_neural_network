# Neural Network from Scratch in Rust

A simple feed-forward neural network implemented **from scratch in Rust**, without using any ML libraries.

The project trains a small 2–3–1 network to learn the **XOR problem** using backpropagation and gradient descent.

## Features
- Custom matrix implementation
- Feed-forward neural network
- Backpropagation
- TANH / Sigmoid activations
- No external ML frameworks
